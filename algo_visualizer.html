💻 Serial BFS

Single-threaded queue-based traversal — the correctness baseline

How It Works

  1. Initialize distance[V] = −1; distance[source] = 0
  2. Push source into FIFO queue
  3. Dequeue front vertex → explore all neighbors
  4. If neighbor unvisited → set dist, enqueue
  5. Repeat until queue empty
↑ The canvas shows one node dequeued at a time (highlighted) processing its neighbors sequentially.

🧵 OpenMP BFS

Shared-memory parallel — level-synchronous with atomic CAS

How It Works

  1. Frontier = flat vector of current-level vertices
  2. #pragma omp parallel for schedule(dynamic,64)
  3. Each thread explores a chunk of the frontier
  4. __atomic_compare_exchange_n (CAS) claims unvisited neighbors
  5. Thread-local buffers → merge after barrier → next frontier
↑ The canvas shows frontier nodes colored by thread assignment. Each color = one thread's workload.

Key Insight: Atomic CAS

CAS on the distance array ensures exactly one thread claims each unvisited vertex — no duplicates, no locks, no races.

🌐 MPI BFS

Distributed-memory — block-partitioned with Allgatherv merge

How It Works

  1. All ranks generate identical graph (same seed)
  2. Block partition: rank r owns [r·V/P, (r+1)·V/P)
  3. Each rank expands shared frontier, claims only owned neighbors
  4. MPI_Allgatherv merges per-rank discoveries
  5. All ranks update distance from merged frontier
↑ The canvas shows rank ownership regions as colored bands. Communication phases are shown between levels.

⚛ Hybrid BFS

MPI + OpenMP — hierarchical parallelism for clusters

How It Works

  1. MPI handles distributed graph partitions
  2. OpenMP threads handle local frontier exploration per rank
  3. Reduces MPI communicator overhead by aggregating work
  4. Hybrid Sync: OpenMP barrier → MPI Allgatherv

🚀 CUDA BFS

GPU-accelerated — CSR graph + kernel-level parallelism

How It Works

  1. Convert adjacency list → CSR (row_offsets + col_indices)
  2. Copy graph + distance array to GPU global memory
  3. Launch kernel: 1 CUDA thread per frontier vertex
  4. Each thread iterates CSR neighbors; atomicCAS claims discoveries
  5. atomicAdd appends to next frontier; cudaDeviceSynchronize
↑ Canvas shows GPU grid/block structure mapping to frontier. All frontier nodes processed in parallel.
